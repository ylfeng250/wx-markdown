# 把 Markdown 发到微信公众号

写完一篇技术笔记，最烦的不是改措辞，而是把标题、引用、代码块重新在公众号编辑器里点一遍。`wx-md` 就是为这件事做的：本地转成带内联样式的 HTML，打开页面，盖印复制，粘贴即可。

## 它实际做了什么

公众号编辑器几乎不认外部 CSS。类名、`<style>` 标签、Flex 布局，粘贴进去后经常被剥光。所以转换时会：

1. 把 Markdown 解析成 HTML
2. 按公众号能保留的属性写成内联样式
3. 包进一个可打开的预览页，方便你先看再复制

> 复制时带上的是 `text/html`，不是纯文本。这样才能把颜色、间距、代码高亮一起带进编辑器。

## 常用写法都覆盖了

段落里可以有 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`。链接会用公众号熟悉的蓝色：[Markdown 语法](https://commonmark.org/)。

### 列表与任务

- 标题、引用、表格
- 代码高亮
- 本地图片会提示你换成图床

1. 运行 `wx-md article.md`
2. 在打开的页面里点印章
3. 回到公众号后台粘贴

- [x] 先在本地看校样
- [ ] 再检查图片是否已上传

### 表格

| 元素 | 公众号里的处理 |
| --- | --- |
| 标题 | 左色条 / 居中（随主题） |
| 代码块 | 浅底、自动换行 |
| 图片 | 需图床或重新上传 |

### 代码

```js
import { convertMarkdown } from './src/convert.js';

const { html } = convertMarkdown('# 你好，公众号', { theme: 'wechat' });
console.log(html.includes('style='));
```

---

换主题也很直接：

```bash
wx-md examples/demo.md -t ink
```

打开生成的 HTML 后，先看手机框里的校样，再复制到公众号。
